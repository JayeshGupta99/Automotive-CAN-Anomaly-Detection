
# Automotive CAN Anomaly Detection

### Lightweight Machine Learning-Based Anomaly Detection System for Vehicle CAN Data

## Overview

This project was developed as part of my Master's
Thesis in Cybersecurity at MDH University of
Applied Sciences, Germany (2026).

The project focuses on detecting abnormal behaviour
in automotive Controller Area Network (CAN) traffic
using lightweight machine-learning techniques.

## Objectives

- Analyse normal and attack CAN traffic.
- Extract relevant behavioural features.
- Identify abnormal communication patterns.
- Evaluate machine-learning classification models.
- Consider detection performance and computational efficiency.

## Methodology

The analysis focuses on the following features:

- CAN Identifier (CAN ID)
- Payload characteristics
- Message frequency
- Timing information

Classification models are evaluated using:

- Accuracy
- Precision
- Recall
- F1-score
- Computational efficiency
